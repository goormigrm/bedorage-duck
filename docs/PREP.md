## A. 지금 남은 것

- [ ] **실제 폰에서 해 보기** — 가로로 눕혀서 이동 스틱·사격 버튼·자동 조준이 손에 맞는지.
  조준이 너무 느리거나 빠르면 알려 달라(한 틱 회전량을 조절한다). 세로로 들었을 때 안내가 뜨는지도 같이.
- [ ] **다른 네트워크에서 실제 대전 검증** — 가장 중요하다. 같은 PC 브라우저 4개로는 NAT 문제를 못 잡는다.
  - 이상적: 다른 집·다른 회선의 PC 2~4대
  - 차선: 한 대를 폰 핫스팟에 물려서 (NAT 통과 실패 케이스 재현)
  - 안 되면 "폰 핫스팟으로 재시도" 안내가 최종이다. TURN 은 비용 원칙상 쓰지 않는다(C 참고)
- [ ] **실제 브라우저 FPS 확인** — 자동화 창에서는 잴 수 없다. 게임 화면에서 F12 → 콘솔에 붙여 넣으면 5초 평균이 나온다:
  ```js
  let n=0,t0=performance.now();(function f(){n++;requestAnimationFrame(f)})();setTimeout(()=>console.log('fps',(n/((performance.now()-t0)/1000)).toFixed(1)),5000)
  ```
- [ ] **체감 밸런스는 오픈 베타에서** — 봇 계측(`tools/balance.ts`)은 참고일 뿐이다. 카페 댓글로 "이 캐릭터가 너무 세다/약하다" 를 모으면 HANDOVER 의 다이얼 표대로 하나씩 맞춘다.
- [ ] **소리 들어 보고 음량 피드백** — 효과음·배경음 모두 코드로 생성한다. 너무 크거나 작으면 알려 달라(음량 슬라이더는 만들지 않기로 했으니 기본값을 조정한다).

## C. 비용 원칙 (2026-09-04 확정, 바꾸지 않음)

**카드 등록이 필요한 서비스는 무료 티어라도 쓰지 않는다.** 사용량 초과 시 과금 가능성이 있으면 배제한다.

| 항목 | 결정 |
|---|---|
| TURN 서버 (metered.ca, Cloudflare Realtime, Twilio 등) | **배제.** 연결 실패 시 핫스팟 안내로 끝낸다 |
| STUN (Google 공개) | 허용 — 무료, 등록 없음 |
| 시그널링: Trystero 공개 Nostr 릴레이 | 허용 — 무료, 등록 없음 |
| Cloudflare Workers 무료 플랜 | 허용 — 카드 없이 계정만, 한도 초과 시 과금이 아니라 차단. 필요해지면 시그널링용으로 |
| GitHub Pages, Google Fonts | 허용 |

- [ ] (필요해지면) Cloudflare 계정 생성 → Workers 시그널링. 지금은 공개 릴레이로 충분해서 보류.
