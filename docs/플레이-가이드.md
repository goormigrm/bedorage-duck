# 배도라지 덕 — 플레이 가이드

> 처음 하는 사람에게 그대로 보여 주면 되는 문서입니다.
> 주소: **https://goormigrm.github.io/bedorage-duck/**

## 30초 요약

설치도 가입도 없습니다. 주소를 열고, 닉네임을 적고, 캐릭터를 고르고, "시작"이나 "방 만들기"를 누르면 끝입니다.

- **WASD** 이동 · **마우스** 조준 · **좌클릭** 사격(꾹 누르면 연사)
- **우클릭** 정조준 (저격총은 조준경이 켜집니다)
- **Space** 구르기 — **구르는 동안은 총알을 맞지 않습니다**
- **R** 재장전 · **Tab** 캐릭터 교체 · **N** 소리 끄기 · **Esc** 메뉴

## 혼자 하기

1. 닉네임을 적습니다(8자까지). 게임 중 캐릭터 위에 뜹니다.
2. 캐릭터를 고릅니다. 12명 전부 무기와 특기가 다릅니다.
3. 맵을 고릅니다. 구조물은 **매 판 새로 생성**되고, 인원이 늘면 맵도 넓어집니다.
4. 난이도(쉬움/보통/어려움), 봇 수(1~3), 개인전/2v2, 목표 킬(5~50)을 정하고 **시작**.

## 친구랑 하기 (최대 4명)

1. 한 명이 **방 만들기**를 누릅니다. 모드(개인전/2v2)와 목표 킬을 먼저 정합니다.
2. 나머지는 **방 목록**에서 그 방의 "참가"를 누르면 됩니다. 목록에 안 보이면 방 코드(6자)를 직접 입력하거나, 방장이 "링크 복사"로 보낸 주소를 열면 됩니다.
3. 모두가 **준비**를 누르면 자동으로 시작합니다.

> 서버가 없어서 브라우저끼리 직접 연결됩니다. 그래서 공짜이고, 그래서 가끔 연결이 안 됩니다.
> 회사·학교망이나 일부 공유기에서 막히면 **한 명이 폰 핫스팟으로 바꿔서** 다시 해 보세요.

## 이것만 알면 잘합니다

### 1. 안 보이는 게 정상입니다

덕코프처럼 **시야가 제한**됩니다. 벽 뒤나 멀리 있는 적은 화면에 아예 안 나옵니다. 대신 총소리와 총알은 보이니 모퉁이를 조심하세요.

### 2. 헤드샷은 운이 아니라 조준입니다

조준선이 상대 **몸 한가운데를 정확히 지나야** 머리(피해 2배)입니다. 가장자리를 스치면 다리(0.6배 + 절뚝거림)입니다. 우클릭 정조준하면 탄이 덜 퍼져서 헤드샷이 잘 납니다.

### 3. 모래주머니 뒤에 붙으세요

맵 가운데에 있는 낮은 엄폐물입니다.

- 뒤에 **붙어서** 쏘면 내 총알은 넘어가고, **상대 총알은 막힙니다**. 일방적으로 때릴 수 있습니다.
- 단, 상대가 내 머리를 정확히 겨누면 그 총알은 넘어옵니다.
- 계속 맞으면 부서집니다. 터지기 전에 자리를 옮기세요.

### 4. 구르기는 회피기입니다

Space 로 구르는 동안은 **무적**입니다. 기력을 34 쓰고, 기력은 초당 22씩 찹니다. 캐릭터 오른쪽의 세로 막대가 기력입니다.

### 5. 죽었을 때 캐릭터를 바꾸세요

죽어서 기다리는 동안(또는 살아난 뒤 3초 안에) **Tab**을 누르면 캐릭터 선택 창이 뜹니다. 고르는 동안은 소환되지 않아 맞지도 않습니다. 상대가 저격수면 근접으로, 붙는 상대면 산탄총으로 바꾸는 식으로 대응하세요.

## 캐릭터 고르는 법

| 이렇게 하고 싶다면 | 추천 |
|---|---|
| 튼튼하게 버티며 퍼붓기 | **철면덕**(기관총, 체력 290) |
| 무난하게 어디서든 | **침착덕**(소총) · **주우재덕**(소총, 구르기가 멀리) |
| 빠르게 붙어서 한 방 | **풍월덕**(산탄총, 구르기 쿨 절반) · **매직덕**(산탄총, 체력 최고 + 자동 회복) |
| 멀리서 한 방 노리기 | **옥냥덕** · **통닭덕**(저격총) |
| 계속 붙어서 쏘기 | **주펄덕** · **기열덕**(SMG) |
| 치고 빠지기 | **단군덕** · **우원덕**(권총, 빠름) |
| 몸으로 부딪히기 | **승빠덕**(후라이팬 — 총알을 막고 후려칩니다) |

### 저격총 쓰는 법

**반드시 우클릭**하세요. 그냥 쏘면 15도로 퍼져서 거의 안 맞습니다. 조준경을 켜면 멀리까지 보이고, 몸에 맞으면 112, 머리에 맞으면 224로 대부분 한 방입니다. 대신 재장전이 4.3초입니다.
조준경을 켜도 **내 주변은 계속 보입니다**. 멀리 보면서도 붙는 상대를 알아챌 수 있습니다.

### 후라이팬 쓰는 법

거리를 좁히는 게 전부입니다. Space 로 굴러서(무적) 붙고, 붙으면 꾹 눌러 계속 휘두르세요. **앞에서 오는 총알은 기력으로 막습니다**(피해 1당 기력 0.55). 기력이 바닥나면 그냥 맞으니, 기력 막대를 보면서 들어갈 타이밍을 잡으세요.

## 자주 묻는 것

**Q. 렉이 있어요**
참가자 중 가장 느린 회선에 맞춰 돌아갑니다. 핑은 화면 오른쪽 위에 나옵니다. 150ms를 넘으면 체감됩니다.

**Q. 화면이 멈춰요**
브라우저 탭을 뒤로 보내면 화면이 멈춥니다. 게임 창을 앞에 두세요.

**Q. 소리가 안 나요**
브라우저 정책상 화면을 한 번 클릭해야 소리가 납니다. 오른쪽 위 "소리" 버튼이나 N 키로 켜고 끕니다.

**Q. 모바일에서 되나요**
됩니다. **가로로 눕혀야** 합니다. 세로로 들면 "가로로 돌려 주세요" 안내가 뜹니다.
왼쪽 화면을 밀면 이동, 오른쪽 화면을 밀면 조준이고 끝까지 밀면 사격입니다.
오른쪽 가장자리에 조준 / 구르기 / 재장전 / 교체 버튼이 있습니다. 조작은 PC 가 더 편합니다.

**Q. 지난 판 결과를 다시 볼 수 있나요**
로비 아래 "최근 전적" 에 최근 50판이 남습니다(닉네임·킬·데스까지).
같은 방에 있었으면 네 사람 모두 같은 내용을 갖게 됩니다.
**복사** 를 누르면 채팅이나 게시판에 붙여 넣을 글이 만들어집니다.
다만 이 기록은 **이 브라우저에만** 남습니다. 서버가 없어서 전체 순위표는 없고,
시크릿 모드거나 저장소를 지우면 사라집니다.

**Q. 치트 막히나요**
서버가 없어서 못 막습니다. 친구끼리 하는 게임으로 생각해 주세요.
